📐 Méthodologie

L'Indice d'Intérêt CBOR (IIC) est un score composite 0-1000 calculé quotidiennement à partir de données sources vérifiables :

  • Social (30%) — Mentions uniques sur Hacker News, GitHub et réseaux publics (7 jours glissants). Cap : 50 mentions.
  • Adoption (30%) — Sessions uniques d'agents/visiteurs sur cborweb.com (7 jours). Cap : 100 sessions.
  • IETF / Standards (15%) — Mentions liées aux RFC, drafts et standards (7 jours). Cap : 20 mentions.
  • Trafic web (15%) — Pageviews sur cborweb.com (7 jours). Cap : 200 pages.
  • Presse (10%) — Articles publiés référençant CBOR-Web (30 jours). Cap : 10 articles.

Chaque composante est normalisée 0-100 (plafonnée à son cap), pondérée, puis multipliée par 10 pour obtenir un score 0-1000.

Sources : mentions (HN Algolia, GitHub), events_raw (collecteur first-party), articles (pipeline éditorial). Delta = score du jour − score de la veille.
